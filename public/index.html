Настройки

Подключите модель — ключ хранится только в вашем браузере.

Так ассистент представляется в чате. Например: Aura, Nova, Orion — любое имя до 24 символов.

Ключ отправляется только вашему провайдеру через локальный сервер. Он не сохраняется на сервере.

Можно ввести любое имя модели. У OpenRouter есть бесплатные модели с суффиксом :free.
